# Pvulgaris-MYMIV-lncRNAs
Predicted lncRNA Sequences of Phaseolus vulgaris During MYMIV Infection

Overview

This repository contains the predicted long non-coding RNA (lncRNA) sequences identified from Phaseolus vulgaris (common bean) under MYMIV-treated and control conditions.

The dataset was generated as part of the study:

“Identification and characterization of long non-coding RNAs in Phaseolus vulgaris responsive to Mungbean Yellow Mosaic India Virus Infection and deciphering their interaction with miRNAs and mRNAs.”

The deposited files provide the predicted lncRNA sequences identified from the transcriptome data of MYMIV-treated and control P. vulgaris samples.

Files and Description

1. "Pvu_control_lncR.txt"

This file contains the predicted lncRNA sequences identified from the control Phaseolus vulgaris samples, representing the lncRNA dataset obtained in the absence of MYMIV treatment.

The file can be used to access the predicted lncRNA sequences identified under control conditions.

2. "Pvu_treated_lncr.txt"

This file contains the predicted lncRNA sequences identified from MYMIV-treated Phaseolus vulgaris samples.

These sequences represent the predicted lncRNAs identified from plants subjected to Mungbean Yellow Mosaic India Virus (MYMIV) infection/treatment and constitute the MYMIV-responsive lncRNA dataset investigated in this study.

3. "Common_lncrna.txt"

This file contains the common lncRNA sequences identified in both MYMIV-treated and control Phaseolus vulgaris samples.

These common lncRNAs represent sequences detected under both experimental conditions and allow comparison of the lncRNA populations between MYMIV-treated and control samples.

4. "Pvu_total_lncrna.txt"

This file contains the total predicted lncRNA sequence dataset generated from the MYMIV-treated and control Phaseolus vulgaris samples.

It represents the combined predicted lncRNA dataset used for downstream characterization and analysis in this study.

Study Context

Long non-coding RNAs are important regulatory molecules involved in various biological processes, including plant development, stress responses, and defence mechanisms. This study focuses on identifying and characterizing lncRNAs associated with MYMIV infection in Phaseolus vulgaris and further investigating their potential interactions with miRNAs and protein-coding genes.

The deposited sequences provide supporting data for the lncRNA identification and characterization described in the associated manuscript.
